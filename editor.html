Publish to GitHub

This is what updates the public GitHub Pages site. The editor saves a draft in your browser; publishing commits the generated site-data.js directly to your repository.

Important: a static GitHub Pages editor page cannot be truly private. Anyone who knows editor.html can open the interface, but they cannot publish without repository permission. Use a fine-grained GitHub token limited to this repository with Contents: Read and write. The token is kept only in memory for this tab and is never stored in localStorage or written into the website files.
Repository settings are auto-detected on normal username.github.io URLs. Check them before publishing.
