SKANK-E — FUNK / HIP-HOP / JAMAICAN SOUND-SYSTEM WEBSITE
========================================================

WHAT'S NEW
- More distinctive old-school funk / hip-hop / Jamaican sound-system visual identity.
- Animated left/right speaker stacks and a large sound-system rig.
- Browser-generated dub FX buttons: Siren, Echo and Spring.
- Release cover artwork built directly into the design.
- Real SoundCloud, Mixcloud and YouTube iframe support.
- Responsive layout for desktop, tablet and mobile.
- One simple content file (site-data.js) for releases, player URLs and social links.
- New private local editor with live preview and no code editing required.
- Dub Lab is now fully editable: text, FX buttons, synth parameters and custom audio files.

PRIVATE EDITOR — RECOMMENDED
1. Open editor.html locally (double-click it), or run the local server described below.
2. Edit the main text, releases, player URLs, Dub Lab sounds and links.
3. Use the live preview on the right.
4. Changes are auto-saved as a private browser draft.
5. Click "Download site-data.js".
6. Replace the old site-data.js in the website folder with the downloaded one.
7. Refresh index.html and publish when ready.

The editor has NO link from the public website and deliberately disables itself on normal public web hosts. It is meant to run only from file://, localhost, 127.0.0.1 or ::1. This avoids pretending that a client-side password on a static GitHub Pages site would be secure. A truly online/private editor would require authentication and a backend.


DUB LAB EDITOR
The editor can now change the Dub Lab without editing JavaScript:
- Rename/reorder/add/remove FX buttons.
- Change the Dub Lab headline, description, armed message and rig label.
- Tune the built-in Siren, Echo and Spring sound engines.
- Or switch any button to a custom MP3/WAV/OGG file.

For custom audio, put the file in assets/sounds/ and use a relative path such as:
  assets/sounds/my-siren.mp3

The sound file must be uploaded with the rest of the site when you publish.

MANUAL ALTERNATIVE
You can still edit site-data.js directly in a text editor if you prefer.

SUPPORTED URL TYPES
- SoundCloud: https://soundcloud.com/artist/track
- Mixcloud: https://www.mixcloud.com/artist/mix/
- YouTube: https://www.youtube.com/watch?v=VIDEO_ID or https://youtu.be/VIDEO_ID

IMPORTANT
I did not invent Skank-E release titles or platform URLs. The site is fully wired for real embeds, but the actual public links still need to be added because they were not provided in the project files.

FILES

- styles.css       Visual design / responsive layout
- script.js        Menus, embeds, animation and dub FX
- site-data.js     Website content generated by the editor
- editor.html      Private local editing interface
- editor.css       Editor styling
- editor.js        Editor logic / local draft / export
- assets/           Logo and custom Dub Lab sounds (assets/sounds/)

LOCAL PREVIEW
Double-click index.html, or run a small local web server for the most reliable iframe behavior:

Python:
  python -m http.server 8000

Then open:
  http://localhost:8000

Private editor:
  http://localhost:8000/editor.html

GITHUB PAGES
Upload the site to your repository root and enable GitHub Pages from the main branch. The public website does not need editor.html, editor.css or editor.js, so you can leave those three files out of the published repository if you want the cleanest setup. If they are uploaded, editor.html still disables its editing UI on public hosts.
